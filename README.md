# 🎬 Groq AI Story Chatbot

An AI-powered story generation chatbot built using Python and the Groq API.

## Features

- AI-powered story generation
- Hero introduction and elevation
- Heroine introduction
- Powerful villain introduction
- Love and emotional scenes
- Thriller and suspense
- Unexpected twists
- Interval/high-point revelation
- Pre-climax
- Proper and satisfying climax
- Clean plain-text output

## Technologies Used

- Python
- Groq API
- Groq Python SDK

## How to Run

Install the Groq package:

pip install groq

Run the chatbot:

python chatbot.py

## Example

User:
I want a story

Bot:
Generates a complete cinematic romantic thriller story with suspense, emotion, action, twists and a proper climax.
